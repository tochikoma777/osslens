## 1. ★ 真冲突（1 处，已裁决）

### C1 退出码语义冲突

| 来源         | 定义                                                         |
| ------------ | ------------------------------------------------------------ |
| 经验库 §6.5  | `0`=正常（含跳过）· `1`=质量不达标（转 warning 继续）· `≥2`=真错误 |
| osslens 契约 | `0`=完成（**可能已降级**）· `1`=配置错误 · `2`=参数错误      |

**裁决：以 osslens 契约为准。** 理由是它已在 CODEBUDDY §2 与执行手册 §3 双处写死，且与 CI/调度耦合。

**映射表（避免 Agent 按经验库理解错）**

| 经验库的情形                                | 在 osslens 中的落地                                          |
| ------------------------------------------- | ------------------------------------------------------------ |
| 质量不达标                                  | **退出码 0** + 降级标记写进报告元数据块 + `costs.jsonl`（不是退出码 1） |
| 可选源失败 / 未配 key / 配额耗尽 / 预算拦截 | **退出码 0** + 留痕（不是失败）                              |
| 配置错误                                    | 退出码 1                                                     |
| 参数错误                                    | 退出码 2                                                     |
| 真错误（异常）                              | 兜底返回 1，**并**在报告与 `costs.jsonl` 双写                |

> ★ 这就是为什么必须钉死权威顺序：经验库这条本身没错（它服务的是别的项目），
> 但直接套用到 osslens 会让"配额耗尽"被当成失败——**而 osslens 明确要求它是正常完成**。

## 2. 需澄清的边界（1 处）

### C2 降档的定位

| 来源                  | 说法                                                         |
| --------------------- | ------------------------------------------------------------ |
| 经验库 §7.15 省钱顺序 | 持久化 > 缩小范围 > 按条件跳过 > **降档（最不推荐，它削减的是价值）** |
| osslens               | 档位是成本控制的核心机制，配额/预算耗尽即降级                |

**澄清：两者不冲突，osslens 的降级是第四顺位兜底，不是省钱手段。**

| 省钱顺位       | osslens 的对应实现                                           | 状态                   |
| -------------- | ------------------------------------------------------------ | ---------------------- |
| ① 结果持久化   | 外部快照落盘 + sha256；同一输入不重复调用                    | ✅ 已设计               |
| ② 缩小作用范围 | **不喂整仓**（实测：元数据仅占源码 0.76%–9.36%）；上下文按信息密度裁剪 | ✅ 已设计（★ 最大杠杆） |
| ③ 按条件跳过   | 观察期未满不进深挖；off 档零 LLM                             | ✅ 已设计               |
| ④ 降档         | 仅当**配额/预算闸门触发**时降级                              | ✅ 兜底，且必须双写留痕 |

> ★ 一句话给 Agent：**不要为了省钱主动降档；降档只在闸门触发时发生，且必须留痕。**

### 8.4 D14 三类白名单（★ 唯一权威口径）

> 收尾验收中 Agent 自建了 A「环境变量名/占位符」/ B「测试夹具假值」/ C「文档·第三方源码术语」三类，
> 与旧称等价但**措辞另起一套** → 有形成两处真相的风险。此处一次性收口，以后**只引用本节**。

| 类    | 定义                                                     | 等价旧称 / 实例                                              |
| ----- | -------------------------------------------------------- | ------------------------------------------------------------ |
| **A** | 环境变量名、占位符、审计命令自身的裸 `sk-` 串（文档中）  | 「裸串」：`docs/文档维护日志.md` 的 `grep 'sk-'`             |
