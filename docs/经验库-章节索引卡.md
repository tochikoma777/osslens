## 1. 怎么用

```bash
cd docs/ref
grep -n "^## 7\." 经验库-全量.md      # 先看该章有哪些条
sed -n '419,573p'  经验库-全量.md      # 再按行区间读该章
```

> ⚠️ **禁止 `cat 经验库-全量.md` 全文读**（96KB，会稀释注意力且读不完）。

## 3. 高频条目直查（不用翻章）
