# osslens 功能总览

> **性质**：全景定稿（收尾阶段交付），基于仓库已提交文件与 tag 撰写；**不是 SSOT**。
> **权威顺序**：`任务卡 > CODEBUDDY.md > 执行手册 > 设计方案 > 冲突与覆盖清单 > 经验库原文`；本文只做索引与汇编，冲突以上游为准。
> **基准**：截至 2026-11-14（路径 B 代码落点 `main` = `3d2924f`；其后仅每日建池与文档提交；tag `l5` 本地）；历史阶段仍以各 tag 为准。
> **口径**：所有数字均给出可回溯来源；未获得的一律写「未获得 + 原因」，不推测、不补写未读到的正文细节。
> **生成方式**：零 LLM、零网络；全部内容取自已提交文件与 tag，幂等可复现。

## 2. 命令总表

以 `python -m osslens` 为唯一入口（`pyproject.toml` `[project.scripts]` 提供 `osslens` 等价别名）；完整 flag 以 `python -m osslens <cmd> --help` 为准。表据 `CODEBUDDY.md` §2 与 `osslens/cli.py` 注册参数（`cli.py:133-208`）。

| 命令 | 作用 | 关键参数 |
|---|---|---|
| `init` | 建工作区骨架 + `config.yaml` + `patterns/seed.yaml`（已存在则跳过） | 全局 `--root DIR` |
| `pool add <owner/repo>` | 抓真实 GitHub 快照并追加观测 | `--channel hot\|classic\|watchlist` · `--as-of ISO` |
| `pool list` | 按通道分别打分排序（通道不混排） | `--as-of ISO` · `--json` |
| `pool eligible` | 深挖候选（热点需过观察期） | `--as-of ISO` · `--json` |
| `analyze <owner/repo>` | 产出体检报告（五区块固定顺序） | `--depth auto\|off\|fast\|strong` · `--channel` · `--domain` · `--as-of ISO` · `--dry-run` · `--no-ledger` · `--no-sources` |
| `cost` | 本周 / 本月 token、费用、降级与拦截次数、预算剩余 | `--as-of ISO` · `--json` |
| `abstract` | L3 规律抽象（零 LLM 三态召回 / ops 增量 merge / run 记录） | `--as-of ISO` · `--cluster ID` · `--cross`（跨域独立入口） · `--off` · `--dry-run` · `--json` |
| `retention` | T5 缓存保留策略（归档 `src/` 与 `llm_cache/`，真源与 `external/` 零删除） | `--as-of ISO` · `--apply`（缺省 dry-run 不写盘） · `--json` |
| `site` | L4 静态只读站点 / 差异检查（当前 22 产物） | `--out DIR` · `--as-of ISO` · `--check` |

- 全局参数：`--root DIR`（所有子命令共用，`cli.py:135`，默认当前目录）、`--version`（`cli.py:133`）。
- **档位**：`off`（零 LLM）· `fast`（`deepseek-flash`，thinking 关）· `strong`（`deepseek-v4-pro`，thinking 开，已实跑）；模型 / thinking / 输出上限由 `config.yaml → llm` 指定，`api_key` / `base_url` 缺任一即降级 `off`（`CODEBUDDY.md` §2.1）。
- **退出码契约**（`CODEBUDDY.md` §2 / 执行手册 §3）：`0` = 完成（**可能已降级**，降级在报告「运行元数据」块与 `costs.jsonl` 可见）· `1` = 配置错误 · `2` = 参数错误。可选源失败、配额耗尽、预算拦截、未配 key **一律 0**；非 0 只能是真失败。
- **环境变量**：`GITHUB_TOKEN` · `OSSLENS_LLM_API_KEY` · `OSSLENS_LLM_BASE_URL`（名称由 `config.yaml` 的 `github_token_env` / `llm.*_env` 指定，代码不硬编码）。
- 门禁四连：`pytest && ruff check . && ruff format --check . && mypy`（`CODEBUDDY.md` §2.1 / `CONTRIBUTING.md`）。

| **可再生缓存** | `data/snapshots/**/src/`（源码切片 + `manifest.json`）· `data/featcards/` · `data/llm_cache/` · `data/cache_objects/` · `data/cache_archive/` · 任何 DB 索引 | 按 commit 从 codeload tarball 可重拉 → 可丢弃、可去重、可归档清理 |
