## 3. 更新纪律

1. **先提交代码 + 打 tag，再刷新本表** —— 写不出 tag 列就说明顺序错了
2. 版本号变更**必须同步正文**（文档头 + 本表）
3. ⚠️ **不确定的内容标"待核/不可考"，不编**
4. 文档固定文件名、不带版本号；历史由 git 管理
5. ★ 每个里程碑收尾，项目负责人必须刷新 SSOT 与本表，**不能只刷新代码就进下一阶段**
6. ★ **交付前用 grep 核对版本号**（曾发生"声称升版但文件未改"的事故）
