## 变更原则

- 结构、权重、取舍由项目原始需求 + 负责人当前诉求决定；外部模板只作参考。
- 每次模板改动至少三轮"提出 → 自我批评 → 收敛"，并记录改了什么、为什么。
- 正文优先 prose；参数、证据、成本下沉附录；事实 / 判断 / 未获得必须分开。
